# Urban Heat Island Effect – Port Harcourt City LGA

## Project Overview

This project analyses the Urban Heat Island (UHI) effect in Port Harcourt City Local Government Area by combining land surface temperature from satellite thermal imagery and vegetation health using NDVI.

## Problem Statement

Rapid urbanisation in Port Harcourt is creating heat islands that affect public health, energy use, and quality of life. This project provides evidence to help decision-makers implement cooling strategies.

## Data Sources

| Dataset | Source |

| Landsat 8 visible/NIR bands | [USGS Earth Explorer](https://earthexplorer.usgs.gov/) |
